# Item Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clicking an items-table row opens `/items/$itemId`, which loads that item via the existing `GET /items/{id}` and shows title, description, ID, and creator.

**Architecture:** Add a sibling TanStack Router page at `frontend/src/routes/_layout/items.$itemId.tsx` (this is `/items/$itemId`, not a nested table layout). Fetch with already-generated `ItemsService.readItem`. Make `DataTable` accept optional `onRowClick` so only the items table navigates; Copy ID and the row actions menu call `stopPropagation`. Reuse `ItemActionsMenu` on the item page. Missing/invalid IDs toast `Item not found` and redirect to `/items`.

**Tech Stack:** React 19, TanStack Router, TanStack Query, Playwright, existing hey-api `ItemsService`, sonner `toast`.

## Global Constraints

- Do not change backend code. `read_item` in `backend/app/api/routes/items.py` already returns `ItemPublic` (title, description, id, creator) for any authenticated user; 404 if missing. Backend tests already cover it.
- Do not regenerate the OpenAPI client. `ItemsService.readItem({ path: { id } })` already exists in `frontend/src/client/sdk.gen.ts`.
- Do not hand-edit `frontend/src/routeTree.gen.ts`. `@tanstack/router-plugin` rewrites it when Vite sees the new route file.
- Do not add dependencies, new UI kits, or a new `ItemDetail.tsx`. Keep the page in the route file, same as `frontend/src/routes/_layout/items.tsx`.
- Do not add a nested `items/` layout or `<Outlet />` on the table page.
- Do not show `owner_id` or `created_at` on the item page. Fields are title, description, ID, creator only. Empty description renders `No description` (same copy as the table).
- Whole row is the click target. Copy ID and the actions menu must not navigate.
- Admin table uses the same `DataTable` and must stay non-clickable (do not pass `onRowClick` from `frontend/src/routes/_layout/admin.tsx`).
- Not-found copy is exactly `Item not found` via `toast.error("Item not found")`. Do not use `showErrorToast` (that titles the toast `Something went wrong!`).
- 404 and 422 from `readItem` both count as missing (invalid UUID is 422). 401/403 stay on the global handler in `frontend/src/main.tsx`.
- Edit/delete on the item page use existing `ItemActionsMenu` (owner or superuser). Do not duplicate those dialogs.
- After delete from the item page, navigate to `/items`. Do not also toast `Item not found`.
- Auth is already enforced by `frontend/src/routes/_layout.tsx`. Do not add another login check.
- Query key for one item is `["items", itemId]` so existing `invalidateQueries({ queryKey: ["items"] })` in `EditItem` refreshes it.

```tsx
import { useQuery } from "@tanstack/react-query"
import { createFileRoute, useNavigate } from "@tanstack/react-router"
import { AxiosError } from "axios"
import { useEffect } from "react"
import { toast } from "sonner"

import { ItemsService } from "@/client"

export const Route = createFileRoute("/_layout/items/$itemId")({
  component: ItemPage,
  head: () => ({
    meta: [
      {
        title: "Item - FastAPI Template",
      },
    ],
  }),
})

function ItemPage() {
  const { itemId } = Route.useParams()
  const navigate = useNavigate()
  const { data: item, error, isPending } = useQuery({
    queryKey: ["items", itemId],
    queryFn: async () =>
      (await ItemsService.readItem({ path: { id: itemId } })).data,
    retry: false,
  })

  const isMissing =
    error instanceof AxiosError &&
    [404, 422].includes(error.response?.status ?? 0)

  useEffect(() => {
    if (!isMissing) {
      return
    }
    toast.error("Item not found")
    void navigate({ to: "/items" })
  }, [isMissing, navigate])

  if (isPending || isMissing) {
    return <p className="text-muted-foreground">Loading...</p>
  }

  if (error || !item) {
    return <p className="text-muted-foreground">Something went wrong.</p>
  }

  return (
    <div className="flex flex-col gap-6">
      <div>
        <h1 className="text-2xl font-bold tracking-tight">{item.title}</h1>
        <p className="text-muted-foreground">
          {item.description || "No description"}
        </p>
      </div>
      <dl className="grid gap-4 text-sm">
        <div>
          <dt className="text-muted-foreground">ID</dt>
          <dd className="font-mono">{item.id}</dd>
        </div>
        <div>
          <dt className="text-muted-foreground">Creator</dt>
          <dd>{item.creator}</dd>
        </div>
      </dl>
    </div>
  )
}
```
